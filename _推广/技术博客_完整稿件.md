### 一、什么是过拟合，为什么会发生？

过拟合（Overfitting）是指模型在训练数据上表现很好，但在未见数据上表现糟糕的现象。

在量化交易中，过拟合的典型表现：

```
回测表现：★★★★★（完美）
实盘表现：★☆☆☆☆（灾难）
```

为什么会发生过拟合？主要有三个原因：

**1. 参数过度优化**

你在回测时，为了追求更高的收益率，会对策略参数进行大量微调。比如移动平均线的周期，从10日改到12日、15日、17日... 每次调整后都选最好的那个。

最终你选出来的参数，是在特定历史数据上最优的参数，而不是在统计意义上稳健的参数。

**2. 数据挖掘偏差（Data Mining Bias）**

你测试了100个因子，选了表现最好的10个组合。这就像扔了100次硬币，总有一次能连续10次正面。但这不代表你有超能力。

**3. 幸存者偏差**

很多回测数据来自存活下来的公司。那些破产的公司根本不在数据里。你用这种数据训练模型，自然会高估策略的有效性。

### 二、如何检测和防止过拟合？

经过多次踩坑，我总结了一套实用的过拟合检测方法：

#### 方法1：Walk-Forward Analysis（WFA）

这是最经典的过拟合检测方法。基本思想：

```
普通回测：[训练:测试] = [70%:30%] 一次性做完
WFA回测：[训练][测试][再训练][再测试]... 滚动进行
```

具体步骤：
1. 用前60%数据训练策略参数
2. 用中间20%数据测试效果
3. 用后20%数据作为"样本外"验证
4. 向后滑动窗口，重复上述过程
5. 综合所有窗口的结果

丙大山内置了WFA引擎，输入策略代码和参数范围，自动输出过拟合风险评估报告。

#### 方法2：交叉验证的时间序列版本

普通的K-Fold交叉验证不适合时间序列，因为会泄露未来信息。正确做法是：

```python
# TimeSeriesSplit 示例
from sklearn.model_selection import TimeSeriesSplit

tscv = TimeSeriesSplit(n_splits=5)
for train_idx, test_idx in tscv.split(data):
    model.fit(data[train_idx])
    score = model.score(data[test_idx])
```

每次训练只用过去的样本来预测未来的样本，确保没有数据泄露。

#### 方法3：参数敏感性分析

真正的稳健策略，参数微小变动不会导致结果剧烈波动。

测试方法：
1. 找到最优参数组合
2. 在每个维度上加减10%-20%
3. 观察收益率、夏普比率的变化幅度
4. 变化过大说明参数敏感，策略脆弱

丙大山有参数敏感性可视化功能，一图看清哪些参数是"毒药"。

#### 方法4：蒙特卡洛模拟

通过随机打乱收益率序列，生成数千条可能的路径，看原始策略的表现处于什么分位。

如果在95%以上的模拟路径中都表现良好，说明策略可能有真实 Alpha。

否则，很可能只是运气。
